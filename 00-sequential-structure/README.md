# 00 - Sequential Structure

Basic exercises covering fundamental programming flow: input, processing, and output.

## Exercises

All exercises in this module follow a simple structure: read input, process data, and output results.

### Ex001 - Sum of Two Integers
Calculate the sum of two integers entered by the user.

### Ex002 - Circle Area
Calculate the area of a circle given its radius.

### Ex003 - Difference of Products
Calculate the difference between two products.

## How to Run

Using IntelliJ IDEA:
1. Right-click on any `.java` file
2. Select "Run 'ProgramName.main()'"

Using Command Line:
```bash
javac src/ExXXX_*.java
java ExXXX_*
```

## Adding New Exercises

1. Create a new file: `src/ExNNN_ExerciseName.java`
2. Add the problem statement in comments at the top
3. Implement the solution
4. Update this README

## Key Concepts

- User input with Scanner
- Variable declaration and assignment
- Basic arithmetic operations
- Output with System.out
