# 00 - Sequential Structure

Basic exercises covering fundamental programming flow: input, processing, and output.

## Exercises

All exercises in this module follow a simple structure: read input, process data, and output results.

## How to Run

Using IntelliJ IDEA:
1. Right-click on any `.java` file
2. Select "Run 'ProgramName.main()'"

Using Command Line:
```bash
javac src/ExXXX_*.java
java ExXXX_*
```

## Key Concepts

- User input with Scanner;
- Variable declaration and assignment;
- Basic arithmetic operations;
- Output with System.out;
