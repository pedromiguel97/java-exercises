# Java Exercises

Java exercises for practicing programming fundamentals.

## Sequential Structure

Exercises covering the basic flow of a program: input, processing and output.

- `ex001` – Sum of two integers
- `ex002` – Area of a circle
- `ex003` – Difference of products
- `ex004` – Employee salary
- `ex005` – Parts total price
- `ex006` – Geometric areas

## How to run

Open the project in IntelliJ IDEA and run any file in `src/`.
